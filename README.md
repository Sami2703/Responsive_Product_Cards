# Understand This Code for Interview
### Why box-sizing: border-box?

It makes the declared width include padding and border, which makes sizing easier to manage.

### Why width: 30%?

To allow multiple cards to fit horizontally on larger screens.

### Why flex-direction: column on mobile?

Because horizontal space is limited, so stacking cards vertically improves readability.

### Why max-width: 400px?

To prevent the card from becoming unnecessarily wide on certain layouts.
